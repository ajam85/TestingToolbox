# TestingToolbox

Nástroj pro manuální testování software.

## Sestavení .exe

```
npm install
npm run dist
```

Výsledný instalátor bude v adresáři `dist/`.

## Spuštění bez sestavení

```
npm install
npm start
```

## Požadavky

- Node.js 18+
- npm

## Obsah

- Porovnávač textů (diff)
- Testovací data (skupiny s checkboxy)
- Generátor dat (Osoba / Firma / Obecné / Soubory / Hesla)
- Generátor textu (UTF-8, vícejazyčný)
- Časomíra (stopky + časovače)
- Poznámky + Seznam (checklist se zámkem)
- CZ/EN přepínač, světlé/tmavé téma
